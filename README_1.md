# Инвестиционный журнал

Проект по предмету "Технологии программирования", ВШЭ НН, 1 курс.

Программа для учета сделок с акциями российских компаний. Сделки записываются в Excel таблицу, а программа на Python считает по ним статистику и рисует график.

## Что умеет

- выбор тикера из списка (44 акции из индекса Мосбиржи)
- считает прибыль, winrate, доходность и сколько дней держали акцию
- показывает какие акции еще не проданы
- статистика по каждой компании
- график капитала

## Структура

- `main.py` - запуск программы
- `app/` - код программы
- `data/` - excel таблица со сделками
- `docs/` - инструкции
- `requirements.txt` - библиотеки которые нужно установить
- `run.bat` - запуск на Windows

## Запуск на Windows

Установите Python с python.org (с галочкой "Add python.exe to PATH"), скачайте проект и дважды нажмите на `run.bat`. Подробнее в `docs/Тестирование_Windows.md`.

## Установка на Linux

Нужен Python 3. Скачайте проект и установите библиотеки:

```
git clone <ссылка на репозиторий>
cd trade-journal
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Как пользоваться

1. Запустите программу. В первый раз в папке data появится файл `journal.xlsx`
2. Откройте `journal.xlsx` и впишите свои сделки на лист "Сделки", сохраните
3. Снова запустите программу
4. Откроется отчет `output/report.xlsx` со статистикой и графиком

Подробнее в папке docs.

## Библиотеки

- **pandas** - для работы с таблицами
- **openpyxl** - чтобы читать и сохранять excel файлы
- **matplotlib** - для рисования графиков
