# Как проверить программу на Windows

## Подготовка (один раз)

1. Установите Python с сайта python.org (кнопка Download).
   При установке **обязательно поставьте галочку "Add python.exe to PATH"**.
2. Скачайте проект с GitHub: зеленая кнопка **Code → Download ZIP**.
3. Распакуйте архив (правой кнопкой → Извлечь все).

## Запуск

Откройте папку проекта и дважды нажмите на **run.bat**.

Откроется черное окно. В первый раз программа установит библиотеки (около минуты), потом посчитает статистику и сама откроет отчет `output/report.xlsx`.

## Тест 1. Пример из шаблона

Просто запустите run.bat. В окне должно быть:

```
Создан data\journal.xlsx из шаблона, заполните его своими сделками
                     Метрика                Значение
                      Период 10.11.2025 — 01.08.2026
             Закрытых сделок                       8
            Открытых позиций                       1
                  Winrate, %                    50.0
         Итоговая прибыль, ₽                   990.0
  Доходность к вложенному, %                    0.48
Средняя доходность сделки, %                    1.65
 Средний срок владения, дней                      82
               Profit factor                    1.13
    Максимальная просадка, ₽                  4580.0

Готово! Отчет сохранен в output\report.xlsx
```

Откроется `report.xlsx` с листами: Статистика, По компаниям, Расчёт, Открытые позиции, График.

## Тест 2. Добавить продажу

1. Закройте report.xlsx.
2. Откройте `data/journal.xlsx`, на листе "Сделки" в строку 11 впишите:

   | Тикер | Дата покупки | Цена покупки | Количество | Дата продажи | Цена продажи |
   |---|---|---|---|---|---|
   | MOEX | 01.09.2026 | 200 | 100 | 01.10.2026 | 220 |

3. Сохраните journal.xlsx и запустите run.bat.

Должно измениться: закрытых сделок **9**, winrate **55.6**, итоговая прибыль **2990.0**, profit factor **1.4**, период до **01.10.2026**. На листе "По компаниям" появится Московская биржа с прибылью 2000.

## Тест 3. Добавить открытую позицию

1. Закройте report.xlsx.
2. В journal.xlsx добавьте строку **без даты и цены продажи**:

   | Тикер | Дата покупки | Цена покупки | Количество |
   |---|---|---|---|
   | VTBR | 05.10.2026 | 90 | 50 |

3. Сохраните и запустите run.bat.

Открытых позиций станет **2**, остальные цифры не изменятся. На листе "Открытые позиции" появится ВТБ.

## Тест 4. Неверный тикер

В journal.xlsx попробуйте ввести в столбец "Тикер" значение `AAPL`. Excel не даст это сделать, потому что такой акции нет в справочнике.

## Возможные проблемы

- **"py" не является командой** - Python не установлен или не стояла галочка "Add to PATH". Переустановите Python с галочкой.
- **"закройте файл output\report.xlsx"** - отчет открыт в Excel, закройте его и запустите снова.
- Чтобы начать заново, удалите `data/journal.xlsx` - он создастся из шаблона.
