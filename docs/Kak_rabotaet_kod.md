# Как работает код

При запуске `python main.py` программа по очереди вызывает 4 модуля из папки `app`:

```
main.py → loader → metrics → charts → report
```

## 1. loader.py - загрузка

- читает листы "Сделки" и "Справочник" из `journal.xlsx`
- убирает пустые строки
- добавляет к сделкам название компании
- делит сделки на закрытые (есть дата продажи) и открытые

## 2. metrics.py - расчеты

Для каждой закрытой сделки считает: сколько вложено, прибыль, доходность в %, сколько дней держали акцию и прибыль нарастающим итогом.

Потом собирает общую статистику (лист "Статистика") и статистику по компаниям (лист "По компаниям").

## 3. charts.py - график

Рисует кривую капитала (как росла прибыль после каждой продажи) и сохраняет картинку в `output/equity.png`.

## 4. report.py - отчет

Сохраняет все таблицы и график в отдельный файл `output/report.xlsx`. Сам журнал `journal.xlsx` программа не меняет.

## Остальное

- `main.py` - запускает все по порядку. Если `journal.xlsx` еще нет, сначала копирует его из шаблона. В конце сам открывает отчет
- `run.bat` - запуск на Windows двойным кликом: ставит библиотеки и запускает main.py
- `app/__init__.py` - нужен чтобы из папки app можно было импортировать код
